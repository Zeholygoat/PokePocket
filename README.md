# Poké Pocket — The Pocket-Sized Card Club

A responsive, Game Boy-inspired Pokémon TCG collecting companion. Built with plain HTML, CSS, and JavaScript so it can be hosted easily on GitHub Pages or Netlify.

## Features
- Retro handheld console hero and pixel-inspired visual language
- Searchable, filterable card showcase
- Example UK price ranges with a clear non-live-price disclaimer
- Buyer checklist for comparing listings and checking condition
- Interactive pack probability calculator (binomial model)
- Budget planner for saving toward a target card
- Dark display toggle and mobile-friendly layout
- No build step, no API key, no dependencies required

## Run locally
Open `index.html` in your browser.

## Deploy to Netlify
1. Unzip this project.
2. Create a new GitHub repository and upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In Netlify, choose **Add new site → Import an existing project**, connect the repository, and deploy.
4. Build command: leave blank. Publish directory: `.`

You can also drag the unzipped folder into Netlify Drop.

## Important notes
- This is a fan-made educational project and is not affiliated with Nintendo, Game Freak, or The Pokémon Company.
- The displayed prices are illustrative estimates, not live market data or financial advice. Replace them with verified current listings if you publish market prices.
- The default 1.17% pack probability is an illustrative category-level baseline drawn from a research scenario, not an official universal Pokémon TCG pull rate. It does not represent the odds of pulling a particular named card.
- Card art in this prototype is original CSS/pixel-inspired decoration, not official Pokémon card artwork.
